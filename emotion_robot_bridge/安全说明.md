# 安全说明：程序文件操作说明

## ⚠️ 重要：零侵入保证

**本程序运行时绝对不会修改以下系统的任何文件**：

### 📂 原有系统目录（只读，绝不写入）

1. **对话系统目录**：`/home/nvidia/Desktop/companion-agent-memory/`
   - ✅ 只读取：`prototype_demo/.run/current_emotion.json`
   - ❌ 不修改：任何其他文件

2. **机器人系统目录**：`/home/nvidia/sim2real/`
   - ✅ 只调用：已有的ROS接口（topic/service）
   - ❌ 不修改：任何配置文件、launch文件、代码文件

## 📁 本程序自己的文件（只会读写这些）

### 运行时产生的文件

```
emotion_robot_bridge/
├── logs/                              # 日志文件（程序创建）
│   ├── watcher_YYYYMMDD.log          # 监听器日志
│   └── gateway_YYYYMMDD.log          # 网关日志
└── __pycache__/                      # Python缓存（自动生成）
```

### 配置文件（只读）

- `bridge_config.json` - 程序启动时读取，运行时不修改

### 不会复制任何代码文件

本程序设计为**纯新增的独立进程**：
- ✅ 不复制任何原有代码
- ✅ 不修改任何原有文件
- ✅ 不向原有目录写入任何内容

## 🔒 文件操作清单

| 操作 | 文件/目录 | 类型 | 说明 |
|------|----------|------|------|
| 读取 | `prototype_demo/.run/current_emotion.json` | 原有系统 | 情绪标签数据源 |
| 读取 | `bridge_config.json` | 本程序 | 配置文件 |
| 读取 | ROS topic/service | 机器人系统 | 触发接口 |
| 写入 | `logs/*.log` | 本程序 | 日志文件 |
| 写入 | `__pycache__/` | 本程序 | Python缓存 |
| 调用 | ROS接口 | 机器人系统 | 触发动作 |

## ✅ 回退验证

停止本程序后，原有系统完全不受影响：

```bash
# 停止程序
pkill -f emotion_watcher.py
pkill -f robot_gateway.py

# 验证对话系统 - 仍可正常写入 current_emotion.json
# 验证机器人系统 - 手柄仍可正常触发动作
```

## 🛡️ 安全设计原则

1. **只读原则**：对原有系统只读取不写入
2. **进程隔离**：独立进程，不修改原有代码
3. **可回退性**：停止进程即完成回退
4. **日志只写自己目录**：所有日志都在 `emotion_robot_bridge/logs/`
