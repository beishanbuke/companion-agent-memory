## 6. 优化假设

### 6.1 高优先级

**问题 1：课程/学术细节记忆弱**
- 现象：5 门课程、strengths/weaknesses 没有在后续引用
- 假设：memory extractor 对列表类信息提取不够
- 建议：增强 `llm_extractor.py` 对列表型事实的提取能力，或增加 academic 专门的 memory slot

**问题 2：偏好类信息未在 policy 中使用**
- 现象："不喜欢被教育/加油"、"喜欢 30-60 分钟动作"未影响后续回复策略
- 假设：preference_slots 没有被 policy_planner 读取
- 建议：在 policy_planner 中增加 `preference_aware` 逻辑，根据用户偏好调整 tone

### 6.2 中优先级

**问题 3："别记这个"回应可以更温暖**
- 现象：Turn 22 "懂的。" 过短
- 建议：在 response_policy 中为 do-not-remember 场景增加温暖确认语，如"放心，不记，继续说"

**问题 4：旅行风格后续未引用**
- 现象：Turn 10 接住了"慢慢逛"，但后续没有引用
- 建议：增强 episodic memory 的 weight，让近期事件在 5-10 轮内保持活跃

### 6.3 低优先级

**问题 5：课程列表可以作为 thread 保持**
- 建议：当用户提及课程/学业压力时，自动创建 "学业" thread，后续主动询问进展
